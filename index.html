🧬 版權淨空的原創身分

與市面上多數依賴「盜用明星聲音」的 AI 翻唱不同，本專案的根源為 Suno AI 所生成的虛擬音軌。

我透過精密調校提示詞以生成理想的音色與唱腔，隨即以此全合成、無實體真人的音源建立 Dataset。成功證明了不侵犯任何實體人格權的「AI 原創數位人聲」建模是可行的。

⚠️ 技術重構與已知限制

挑戰：儘管經歷 400 Epochs 的深度訓練，並在 Audacity 套用降噪與低通濾波，最終轉換的人聲在高頻激動處仍會出現「嚴重電子音」或「合成頻率崩潰」。

根本原因分析：
1. Dataset 相位污染： Suno 原始生成檔案本身即具有 AI 計算產生的微觀相位失真，UVR5 雖洗出人聲，但失真特徵一同被模型吸收。
2. RMVPE 提取極限： RVC 音高提取演算法在面對複雜動態或非純淨基頻時，容易發生誤判，導致輸出特徵碎裂 (Artifacts)。

LLM 自動化工作流與教學系統設計

使用 Make.com 串接 Gemini API 解決影視與新聞採編痛點，並獨創五維度 SOP 教學模組實現團隊的高效 AI 轉型賦能。

針對影視製作與新聞採編的流程痛點，使用 Make.com 串接 Google Gemini LLM API，建構兩套端到端（End-to-End）無人化腳本生成系統：

🎬

1. 多模態自動化分鏡腳本生成

⚡ 事件驅動觸發 (Event-Driven Trigger) 實時監控雲端資料庫（如 GCS/Drive），實現影視素材一上傳即刻自動啟動後台流程。
🧠 LLM 結構化輸出 (JSON Enforcement) 調用 Gemini API 的多模態理解能力解析音畫內容，並引導模型嚴格輸出標準 JSON 結構，消弭生成隨機性。
📊 ETL 自動化寫入 (Automated Ingest) 後端自動解析 JSON 格式資料流，並複製標準分鏡試算表模板，自動完成鏡號、畫面描述、音效等欄位的填入與存檔。
📰

2. 即時新聞流 AI 口播腳本與推送

📡 RSS 擷取與批次分流 (Parallel Iterator) 自動定時抓取新聞 RSS 資訊源，搭配 Make 的 Iterator 運算子，實現多筆新聞的獨立並行處理（Parallel Processing）。
✍️ 文本聚合與語意改寫 (Text Aggregator) 運用 Text Aggregator 整合新聞內容，交由 Gemini 改寫為適合短影音的 60 秒結構化口播腳本。
📧 多管道自動分發 (Multi-Channel Dispatch) 解析完口播數據後，自動寫入雲端資料表歸檔，並同步觸發 Email 即時推播給主播或團隊。

LayoutDiff：可變版型電子檔檢測系統

針對非固定模數、多尺寸混排與不規則印刷版面，設計並驗證之高精度電子檔檢測原型。
支援智慧模位邊界偵測、人工防呆檢視、自適應角點準星對位，以及逐模位限定 ROI 零容差像素差分引擎。

造訪 GitHub 開源倉庫 ↗ 18/18 Tests PASS (合成測試) 幾何 IoU ≥ 0.9909
🎯

問題背景：突破固定網格之傳統限制

傳統印刷檢測系統多仰賴預設模數、單一尺寸或均勻網格切割。當生產版面轉為混款、缺格、密集或不規則排列時，固定規則容易產生漏檢、黏框或誤把板材外圍納入比對等誤報。
LayoutDiff 核心在於「自適應幾何分群」與「限定模位 ROI 差分」：自動識別標籤輪廓、依長寬聚合分群，並只在人員確認之有效模位框內進行逐像素運算，確保零誤報與極限精準度。

四階段工業級檢測工作流

STEP 01

上傳 Golden 母本

自動萃取版面邊緣輪廓，計算四角準星特徵與模位幾何框，依模位長寬自動聚合分群。

STEP 02

人工檢視與建版

提供 Web Canvas 縮放、微調與重疊防呆診斷，人員確認模位邊界與準星品質後保存版型 Profile。

STEP 03

待測檔幾何對位

依準星範本執行幾何對齊；尺寸不符或對位信心不足自動警示並轉入 REVIEW 狀態，拒絕誤判。

STEP 04

限定模位像素差分

只在保存之有效 ROI 內比對，精確回報差異像素座標與所在模位編號，排除外圍背景干擾。

工程發現：像素相等 ≠ 視覺相等

外部影像經過不同壓縮或重新編碼（如 JPEG）後，即使肉眼看起來完全相同，解碼後之數值矩陣仍可能因量化雜訊產生細微差異。零容差檢測流程能精確標示此差異；因此「準星成功對位」並不等同於「模位內容必然逐像素相符」。此發現奠定了工業檢測需嚴格界定「編碼差異 vs 物理缺陷」之理論基礎。

📐

對位的亞像素邊界觀察

在整數像素平移情境下，準星估計算法可完美復原並達成 0 差異。但若涉及小數像素平移（如 +2.5, −1.3 px）或微小旋轉（0.15°），影像重採樣（Resampling）將在邊緣產生過渡像素，導致全版模位受波及。專案將此現象實測文件化，為後續產線實裝提供了清晰的物理極限邊界。
